# MiniClaw 流畅度优化报告（v2 · 复核后修订）

- **日期**：2026-09-19
- **范围**：`MiniClaw/`（App / Views / Services / Tools / Models）为主，含 `MiniClawKit/`、`MiniClawWidget/`、`ShareExtension/`
- **v1 方法**：6 个只读子代理静态审计（并发调度 / 后台与磁盘 IO / 聊天列表渲染 / 启动与交互 / 流式网络与运行时 / 存储与媒体管线）
- **v2 方法**：**5 个独立复核子代理**（4 个分区复核 + 1 个中途失败后重派的对抗性证伪者）逐条裁定，"只保留真问题"；本报告作者另行打开源码复核了全部 P0/P1 与 8 处关键纠错
- **未做**：未修改任何代码（`git status` 仅本文件）、未构建、未跑 Instruments。所有 ms 数为代码路径推算
- **严重度口径**：**P0** = 会导致"只能杀 App / 主循环永久卡死 / 确定性崩溃"；**P1** = 明确主线程卡顿、崩溃窗口或数据完整性风险；**P2** = 有条件的帧成本/IO/内存；**P3** = 卫生问题或需实测才能定性

## 0. 复核结论速览

**裁定统计（v1 共 51 条，复核后）**：**站得住 31 条** ｜ **降级改判 12 条** ｜ **删除误报 2 条** ｜ **措辞与引用纠错 8 条**（其中 1 条严重度被复核者错误下调、又由证伪者推翻，见 §2 第 3 条）。

**v1 → v2 最重要的 5 个变化**：

1. **v1 把 4 处"竞速超时"都算 P0，实际只有 2 处会造成挂死**：`SubagentWarmupGate` 与工具超时（有真实受害者 `HomeKitTools`）；`StdioMCPClient` 那段在 `#if os(macOS)` 内且**五个 target 全为 iOS** → 当前构建不可达（P3 潜在）；`MiniClawTabPool` 有 `defer release` 兜底，**不会挂死**（P2）。
2. **两条误报必须删**：`B23①`（"浏览器整页 body 随进度 KVO 频率重算"——`loadingProgress` 只有 2 个写入点，全仓无 `estimatedProgress`/`observeValue`）；`B20`（"运行时状态页主线程冻结"——`gatherRuntimeStatus` 是文件级 nonisolated async，按 SE-0338 不在主线程；只有将来启用 SE-0461 才会变真）。
3. **频率与成本普遍被高估 2–10 倍**：`updateBridge` 只在 bridge 首次创建时调用（→P3）；`seedHeights` 的触发源不是 0.1 s 的 `flushStreamingLayout` 而是 `$messages` sink ≈4 Hz；`B4/B21/B22/B13` 都降级。
4. **一处改法被明确否决**：`TokenUsageTracker` 的"改 `map[key, default:]`"**无效**（`@Published settings` 整结构拷贝照样发生）；`CrashReporter` 心跳"改 5 分钟"会削弱它唯一的存在价值（代码注释写明 30 s 是为"死前内存真值"）。
5. **统一机制方案成型**：14 个合并簇（6 个 P0/P1），其中"竞速超时"这条最该做——**同一写法被抄了 4 份**，而仓内已有两份同型正确实现（`SnapshotBox`、`OnceBox<T>`）却没被复用。

### 3.3 六个关键簇的设计摘要

**C1 可取消超时 + `ResumeOnceBox`（P0，最该做）**

```swift
// MiniClaw/Services/Shared/ResumeOnceBox.swift
final class ResumeOnceBox<T: Sendable>: @unchecked Sendable {
    private let lock = NSLock(); private var cont: CheckedContinuation<T, Never>?
    @discardableResult func finish(_ v: T) -> Bool {   // 恰一次；false = 已被别人定稿
        lock.lock(); let c = cont; cont = nil; lock.unlock()
        c?.resume(returning: v); return c != nil
    }
}
// MiniClaw/Services/Shared/CancellableTimeout.swift
/// 超时**取消被等待的任务**，绝不 race。
func withCancellableTimeout<T: Sendable>(_ seconds: TimeInterval,
    onTimeout: @Sendable @escaping () -> T,
    work: @escaping @Sendable () async -> T) async -> T
```

- **现状重复点**：竞速超时 4 处（`AgentLoopEngine.swift:2200-2248`、`StdioMCPClient.swift:97-114`、`SubagentWarmupGate.swift:44-49`、`MiniClawTabPool.swift:526-537`）；resume-once 盒 5 份不同名（`PhotosTools.swift:359-372 OnceBox<T>`、`SpeechTools.swift:316-360 TranscriptBox`、`LinuxShellRuntime.swift:10-18 FinishOnceGuard`、`MiniClawBrowserEngine.swift:500-537 SnapshotBox`、`RemoteHostTool.swift:559-577 BonjourProbe.resumed` 裸 `nonisolated(unsafe)`）。
- **纪律**：`ResumeOnceBox` 只做一次 resume，**绝不在锁内调用外部闭包**（照 `ToolTaskBag` 的"锁内只读写、回调在锁外"）；`SnapshotBox` 需要 `DispatchSourceTimer` + 主队列约束 ⇒ 让它**组合** `ResumeOnceBox` 而非被替换。
- **迁移顺序**：新增文件（零调用点）→ 先改 `StdioMCPClient`（macOS-only，等价性最好写）→ `SubagentWarmupGate`（`relinquishLead` 显式 signal）→ `MiniClawTabPool` → **最后** `AgentLoopEngine:2200-2248` → 逐个把 5 个盒改为**持有** `ResumeOnceBox`。
- **不变量**：`ToolTaskBag` 的"一次停止取消整批"语义不能改；`MiniClawTabPool` 的 token 身份校验不能省；工具超时**不覆盖** `executionTimeout == nil` 的长时编排工具（设计如此）。
