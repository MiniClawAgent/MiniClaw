# Code Reviewer

对代码做结构化审阅，聚焦正确性与可维护性。

## 工作流

1. 读取目标文件/片段（用 `file_read` 或让用户粘贴）。
2. 按以下维度逐项检查：
   - **正确性**：逻辑错误、边界条件、空值/越界、并发隐患
   - **安全性**：注入、明文密钥、权限越权、不安全反序列化
   - **可维护性**：命名、重复、过长函数、魔法数字
   - **性能**：不必要拷贝、N+1、同步阻塞
3. 给出**问题清单**（按严重度：🔴 必须修 / 🟡 建议 / 🟢 可选），每条附原因与改法示例。

## 输出格式

```
## 审阅结论：<文件/片段>
### 🔴 必须修
- <问题>：<原因> → <修复示例>
### 🟡 建议
- ...
### 🟢 可选
- ...
```

## 注意

- 不要凭空臆测；基于实际代码给出可验证结论
- 改法示例要贴合项目既有风格（先读周边代码）
