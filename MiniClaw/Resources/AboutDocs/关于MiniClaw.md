# 关于 MiniClaw

MiniClaw 是一款运行在 iOS 上的**本地优先智能体应用**。它把大模型、本地 Linux 运行环境（基于 iSH / Alpine）、以及一组工具（文件、浏览器、Shell、记忆等）整合在一起，让你能在手机上完成自动化的多步任务。

## 核心特性

- **本地 Linux 环境**：内置 Alpine Linux 用户态，Agent 可在隔离的文件系统中执行命令、运行脚本。
- **多模型接入**：支持通过 API Key 接入主流大模型，按会话灵活选择。
- **工具集**：文件读写、网页浏览、Shell 执行、记忆读写等，覆盖日常自动化场景。
- **会话隔离**：每个会话拥有独立的文件空间，互不干扰。
- **后台能力**：支持灵动岛实时活动、画中画与任务完成通知。


## 开源组件

本应用直接使用的开源组件：**iSH**（本地 Linux 用户态运行时）、**swift-cmark**（Markdown 解析）、**SwiftMath**（数学公式排版）。完整清单、许可证与设计参考来源见「鸣谢」。
