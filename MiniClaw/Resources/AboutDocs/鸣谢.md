# 鸣谢

MiniClaw 站在这些开源项目的肩膀上。感谢每一位作者与维护者。

## 直接使用的开源组件

- **iSH** — 本地 Linux 用户态运行时
  许可证：GPLv3，另见 iSH 针对 iOS 分发的附加条款（`LICENSE.IOS`）。

- **swift-cmark / cmark** — Markdown / CommonMark 解析
  许可证：BSD 2-Clause，Copyright © 2014 John MacFarlane。

- **SwiftMath** — 数学公式（LaTeX）排版
  许可证：MIT，Copyright © 2023 Computer Inspirations。

## 设计与主题参考

- **MarkdownUI** — 聊天区 Markdown 主题的观感参考。本项目以 UIKit 自行实现同类效果，未直接引入其代码。
