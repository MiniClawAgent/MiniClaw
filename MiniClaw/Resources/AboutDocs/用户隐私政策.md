# 用户隐私政策

**最后更新：2026 年 9 月**

MiniClaw（以下简称"本应用"）重视你的隐私。本政策说明本应用如何处理与你相关的信息。

## 一、我们收集的信息

本应用遵循**本地优先**原则，绝大多数数据仅存储于你的设备：

1. **对话与文件**：你创建的会话、消息、附件、浏览器数据及 Agent 生成的内容，默认保存在本机沙盒中。
2. **设置项**：包括模型配置、外观偏好、后台与权限设置等，保存在本机。
3. **API Key**：你配置的第三方大模型 API Key 仅存储于本机钥匙串 / 沙盒，不会上传给开发者。
4. **系统数据与设备能力**：经你在「设置 → 权限与后台 → 控制」中授权后，AI 才可访问以下本机数据，且仅用于你就该次对话发起的请求，**不会上传给开发者**；你可随时在系统设置中撤销授权。
   - **健康数据（HealthKit）**：读取活动与步数、心率、睡眠、血压 / 血糖 / 血氧等，用于回答你的健康相关提问；按你的要求向「健康」App 写入条目由「允许 AI 写入健康数据」开关单独控制（默认关闭）。
   - **家庭配件（HomeKit）**：读取你家中已配对的配件与场景，并按你的要求执行控制（如开灯、调温、运行场景）。

## 二、我们**不**收集的信息

1. 我们**不会**将你的对话内容、文件或 API Key 上传到任何由开发者控制的服务器。
2. 我们**不会**在后台静默收集你的设备标识符用于广告追踪。
3. 本应用不内置任何第三方广告或统计 SDK。

## 三、第三方服务

1. 当你使用本应用调用大模型时，你的对话内容会按照你所配置的模型提供方的要求，发送至该提供方的 API。**该等数据的处理受相应提供方的隐私政策约束**，请自行查阅。
2. 若你开启网页浏览功能，相关请求由系统网络栈直接发起，不经过开发者服务器。

## 四、数据的存储与删除

1. 你可随时在应用内删除单个会话、附件或清空本地数据。
2. 卸载本应用将移除本机沙盒内的全部相关数据。
3. 若你开启跨设备同步（如 iCloud），相关数据会按对应服务的规则在设备间同步，具体以该服务的条款为准。

## 五、儿童隐私

本应用不面向未满 13 周岁（或所在司法辖区法定年龄）的儿童。我们不会主动收集儿童个人信息。

## 六、政策变更

我们可能不时更新本政策，更新内容将在应用内发布。

## 七、联系我们

如对本政策有任何疑问，可通过应用内的反馈渠道与开发者联系。
